Conventions: `runs/<run_id>/<dataset>/` holds `manifest.json` (status, config and its SHA-256, versions, timings,
peak memory, chunk statistics; runs created from 2026-10-24 also record a SHA-256 content digest of the code and of
every input file), `queries.json` (question IDs and document indices only, no text) and one `.npz` of per-query
metric values per chunking. `analysis/<run_id>/` holds `results.json`, `results.md` and figures generated by
`python -I -m ragmv.analyze` and `python -I -m ragmv.figures`. Every result file states EXPLORATORY, CONFIRMATORY,
SMOKE or POSTHOC. Failed runs are kept and logged. Historical runs and analyses are never overwritten: new analyses
go to new directories (`analysis/posthoc-*` are the 2026-10-24 post-hoc sensitivity analyses).

Historical manifests originally recorded Git commit identifiers; the original repository history is unavailable, so
those values were replaced by a marker (`docs/repair/HASH_REDACTIONS.md`). The Gemini (`runs/gemini36flash-20261019`,
21 rows) and CPU (`runs/qwen3-4b-20261019`, 198 rows) generation runs are aborted runs kept as evidence and not analysed.
